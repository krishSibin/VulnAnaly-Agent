Demo Setup — How to Connect Laptops

Step 1: Copy node_worker.py to each of the 3 target laptops.

Step 2: Find this master laptop's IP (run ipconfig) — e.g., 192.168.1.100

Step 3: On each target laptop, open a terminal and run:

python node_worker.py --node-id node_1 --master-ip 192.168.1.100
python node_worker.py --node-id node_2 --master-ip 192.168.1.100
python node_worker.py --node-id node_3 --master-ip 192.168.1.100

Step 4: Update each node's IP above so the master can dispatch patches to it.

Step 5: When you click "Apply Fix" on the Dashboard, the patch executes live on the target laptop's terminal!

⚠ No network? The master automatically falls back to local simulation — the demo will never break.
